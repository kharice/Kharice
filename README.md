#  About Me:
<br>Hey!!! <br>I'm Kharice, a data engineering student interested in building reliable data pipelines and turning raw data into something useful. I like understanding how data moves from its source to the final dashboard or model, and making that journey clean, fast, and easy to maintain. Right now, I'm learning and practicing tools like Python, SQL, PowerBI and I'm getting more comfortable working with databases, and data transformation. <br>I learn best by building things, so this GitHub is where I share my projects, experiments, and progress along the way. Some are simple, some are messy, but each one teaches me something new.<br>I'm currently looking for opportunities to grow, collaborate, and gain hands-on experience in data.<br>Feel free to explore my work or reach out. I'm always happy to chat and learn from others!
